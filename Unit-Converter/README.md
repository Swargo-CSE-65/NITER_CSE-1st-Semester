# Unit Converter

A simple **Unit Converter** program written in **C**.

## Features

This program can convert:

1. Kilometer to Meter
2. Meter to Kilometer
3. Celsius to Fahrenheit
4. Fahrenheit to Celsius
5. Kilogram to Gram
6. Gram to Kilogram
7. Liter to Milliliter
8. Milliliter to Liter

## Technologies Used

* C Programming Language
* `stdio.h`
* `switch-case`
* `scanf()`
* `printf()`

## How to Run

Compile the program:

```bash
clang unit_converter.c -o unit_converter
```

Run the program:

```bash
./unit_converter
```

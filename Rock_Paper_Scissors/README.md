# Rock Paper Scissors Game

A simple **Rock Paper Scissors** game written in **C Programming Language**.

## 🎮 Features

The player can choose:

1. Rock
2. Paper
3. Scissors

The computer randomly selects one option, and the program determines the winner.

## 🏆 Game Rules

* Rock beats Scissors
* Paper beats Rock
* Scissors beats Paper
* Same choice = Draw

## 🛠️ Technologies Used

* C Programming Language
* `stdio.h`
* `stdlib.h`
* `time.h`
* `switch-case`
* `if-else`
* `rand()`
* `srand()`

# Simple ATM

A simple **ATM Management System** written in **C Programming Language**.

## Features

This program provides the following ATM operations:

1. Check Balance
2. Deposit Money
3. Withdraw Money
4. Exit

## Technologies Used

* C Programming Language
* `stdio.h`
* `if-else`
* `switch-case`
* `scanf()`
* `printf()`

## Starting Balance

## Operations

# Check Balance

Shows the current account balance.

# Deposit Money

Allows the user to deposit money into the account.

# Withdraw Money

Allows the user to withdraw money if sufficient balance is available.

# Exit

Closes the ATM program.

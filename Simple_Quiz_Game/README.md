# Simple Quiz Game

A simple **Quiz Game** written in **C Programming Language**.

## Features

* 5 multiple-choice questions
* User can select an answer
* Correct answers increase the score
* Final score is displayed
* Result message based on the score

## Technologies Used

* C Programming Language
* `stdio.h`
* `if-else`
* `scanf()`
* `printf()`
* Increment operator `++`
